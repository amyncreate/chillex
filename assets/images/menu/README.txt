Put menu item photos here.

See /PHOTOS.md (project root) for 5 ready-to-download CC0 photos and the
exact filenames they should be saved as — that's the fastest way to get
started.

Naming: any filename works, as long as it matches the `image` field you set
for that item in /assets/js/data.js (e.g. image: 'chicken-shawarma.jpg' means
this folder needs a file named exactly chicken-shawarma.jpg).

Recommended: square photo, at least 600x600px, JPG or WebP, under ~150KB so
it loads fast on mobile data. If a referenced file is missing, the site just
shows the category icon instead -- nothing breaks.

You can delete this file once you've added real photos.
